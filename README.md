## Deskripsi Project

PawHouse merupakan website bertema cat adoption yang dibuat menggunakan HTML, CSS, dan JavaScript.

Website ini menyediakan informasi mengenai kucing yang siap diadopsi serta halaman kontak untuk pengguna yang ingin memberikan rumah baru bagi kucing.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- Feather Icons
- Google Fonts
